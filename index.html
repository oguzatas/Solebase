Encryption

Passphrase encrypts cloud sync and manual exports (AES-GCM). Session-only — never written to disk. Forgot passphrase = data unrecoverable.

Google Drive

Optional. Create an OAuth 2.0 Web client in Google Cloud Console. Authorized JS origin = this page’s origin. Scope: drive.appdata. Prefer WebDAV/S3 when possible.

WebDAV

Recommended. Nextcloud example: https://cloud.example/remote.php/dav/files/USER/Prompt2UI/

S3-compatible

Recommended. Cloudflare R2, MinIO, or AWS S3. Enable CORS for this origin (GET, PUT, HEAD).

Sync & backup

Saving a remote adapter + passphrase turns on automatic sync (debounced writes, online, visibility). Manual push/pull available anytime.
